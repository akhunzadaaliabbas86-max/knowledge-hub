Python 3: The Complete Starter's Field Guide

Chapter 1: Getting Started with Python

Python is an interpreted, high-level, general-purpose programming language. Its design philosophy emphasizes code readability through significant indentation.

Your First Program: Hello World

Execute this code block in your interpreter or editor:

print("Hello, World!")

Chapter 2: Core Data Types & Variables

Python automatically assigns variable types based on the assigned data value.

  • int - Whole numbers (e.g., age = 25)
  • float - Decimals (e.g., price = 19.99)
  • str - Strings of text (e.g., name = "Alice")
  • bool - Truth conditions (True or False)

Chapter 3: Control Flow (Conditionals & Loops)

Control flow structures enable decision-making within programs.

# Decision Making
score = 85
if score >= 80:
    print("Grade: B")
else:
    print("Grade: C")

# For Loop
for i in range(3):
    print("Iteration:", i)
