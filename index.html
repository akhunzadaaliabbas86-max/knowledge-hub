EDUCATIONAL DEFINITIONS & KEYBOARD PREFACES
================================================================================
1. TYPING DEFINITIONS:
   - English Typing: The motor-cognitive execution of translating textual thought into accurate alphanumeric keystrokes using standardized finger placement.
   - Urdu Typing: The specialized orthographic input method relying on right-to-left character joining, contextual shape morphing, and phonetic keyboard mapping.

2. KEYBOARD LAYOUT COMPARISONS:
   - QWERTY vs. QVERTZ: Detailed analysis of character position shifts ('Y' and 'Z'), impact on European vs. English typing ergonomics, and finger travel fatigue.
   - Jameel Noori Nastaliq vs. System Urdu Fonts: Contrast calligraphic Nastaliq ligatures with standard Naskh vector rendering, highlighting legibility, line-height demands, and display rendering speed.

3. HARDWARE & FONT SELECTION GUIDE:
   - Urdu Brochures / Small Prints: Use Jameel Noori Nastaliq for traditional aesthetics and cultural authenticity.
   - Large Flex Banners / Billboard Publishing: Use bold Naskh or modern geometric Urdu fonts for high-distance legibility and sharp vector scaling.
   - English Print & Web Standards: Use clean sans-serif variable fonts (e.g., Inter, Roboto) for UI/Web, and serif fonts (e.g., Merriweather) for high-density print books.
